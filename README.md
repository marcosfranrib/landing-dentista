# Landing page — Dr. Bruno Jordão

Estrutura:
- index.html  → marcação (Bootstrap 5.3 via CDN)
- css/style.css → paleta (variáveis CSS) e estilos
- js/main.js  → CONFIG (WhatsApp e mapa), menu e destaque de seção
- img/        → coloque aqui as fotos e troque os blocos [FOTO ...] por <img>

Para publicar: edite o CONFIG em js/main.js (número do WhatsApp e URL do mapa) e abra index.html.
